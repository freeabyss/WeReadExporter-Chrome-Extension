# 微信读书导出助手 · Chrome 扩展

在**微信读书网页版**一键导出 **当前章节** 或 **整本书全文**，支持 **Markdown / HTML / TXT**。

![面板截图](docs/panel.png)

## 来历

本项目由 [WeReadExporter-Tampermonkey](https://github.com/henonguan1688-lab/WeReadExporter-Tampermonkey)（MIT）的油猴脚本改造而来：去掉 Tampermonkey、jQuery 和远程依赖，做成一个可以直接装进 Chrome 的扩展（Manifest V3）。

改造时修复了原脚本 **无法导出全文** 的问题——它请求章节时只拿到一小段试读，TXT 格式的书抓不到内容，会话参数过期后也不会刷新。现在会逐章抓取整本书、校验内容是否完整、失败自动重试，并把导不出来的章节明确列出来。

项目地址：https://github.com/freeabyss/WeReadExporter-Chrome-Extension

## 安装

### 方式一：下载 Release（推荐）

1. 到 https://github.com/freeabyss/WeReadExporter-Chrome-Extension/releases 下载 `weread-exporter-v1.3.0.zip`，解压到一个**固定目录**（解压后不要移动或删除）。
2. Chrome 地址栏输入 `chrome://extensions/`，打开右上角 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择刚才解压的目录。
4. 打开 <https://weread.qq.com/web/shelf> 并登录，进入任意一本书的阅读页；页面右下角出现蓝色 **「导出」** 按钮即安装成功。

### 方式二：直接加载源码目录

开发调试时，clone 本仓库后在 `chrome://extensions/` 里「加载已解压的扩展程序」直接选择仓库根目录（包含 `manifest.json` 的目录）。需要自行打包时运行 `npm run package`，会在 `dist/` 生成同样的 zip。

> 支持 Chrome / Edge 等 Chromium 内核浏览器（Chrome 102+）。更新时重新下载解压，再到 `chrome://extensions/` 点该扩展的刷新按钮即可。

## 使用

1. 在阅读页点右下角 **「导出」** 展开面板。
2. 选择输出格式：**Markdown / HTML / TXT**。
   - Markdown：`# 书名` + 章节 `## 标题`，保留段落与图片；
   - HTML：单文件，带目录、响应式排版、深色模式，可直接用浏览器打开；
   - TXT：纯文本，适合任意阅读器。
3. 点 **「导出全文」**：进度条实时显示逐章抓取进度，可随时点「取消导出」；完成后自动下载文件，结果卡片里还能再次「下载文件」或「复制全文」。
4. **当前章节**：「复制本章」「下载本章」。
5. **章节列表**：点章节标题跳转到该章；每行可单独复制/下载；导出后显示 ✓ 成功 / ⚠ 内容可能不完整 / ✕ 失败。有失败章节时点「重试失败」补齐，已成功的章节会缓存、不会重复抓取。
6. **导出内容（可多选）**：面板上只有一个 **「导出」** 按钮，导出什么由三个勾选项决定：
   - **全文** → 下载《书名》。md/html/txt
   - **笔记** → 下载《书名 - 笔记与标注》，我的划线 + 我的想法按章节分组，想法关联到对应划线
   - **附带热门笔记（他人标注）** → 仅在勾选「笔记」时生效，服务端固定返回前 20 条

   两个都勾就一次产出两个文件；只勾一个就只产出一个。「全文」与「笔记」至少保留一项。
   另外「导出全书架笔记」把整个书架的笔记合成**一个文件、按书分组**。
7. **高级设置**：请求间隔、失败重试次数、会话刷新频率、是否附带书名/作者/导出时间。面板可拖拽，位置与偏好会记住。

只能导出你当前账号**有权阅读**的章节；未购买或未解锁的章节会被标为失败，不会被静默替换成空内容。公众号文章暂不支持。所有处理都在浏览器本地完成，扩展不收集、不上传任何数据。
